# Название приложения
Сад и огород-система для оформление заказов
## 1. Название приложения
**Сад и огород**-приложение для оформление заказов садовых пренодлежностей.
## 2. Используемые технологии
- **Язык:** Python 3.12
- **GUI:** PySide6 6.8+
- **СУБД:** PostgreSQL 18.6
- **Драйвер БД:** psycopg2-binary 2.9.10+


## 3. Назначение и основные функции
Приложение автоматизирует продажи. Функции:
- Каталог товаров (изображение, цена, скидка);
- Авторизация по логину;
- Фильтрация, сортировка, поиск;
- Оформление заказа;
- Управление заказами (Менеджер, Администратор).

## 4. Порядок подготовки БД и запуска
1. Установите PostgreSQL 18.6, создайте БД `sad_i_ogorod`.
2. Выполните `db/sad_i_ogorod.sql` в pgAdmin.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите: `python src/main.py`.
